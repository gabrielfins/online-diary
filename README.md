# Online Diary

A web diary project built with **Vue.js**.

> **Status:** just started. The `frontend/` folder is a fresh Vue CLI (Vue 2) project that still shows the default welcome page, and `backend/` is an empty placeholder. No diary features have been implemented yet.

## Structure

```
online-diary/
├── frontend/   # Vue 2 app (Vue CLI)
└── backend/    # Reserved for a future API
```

## Running the app

Requirements: Node.js and npm.

```bash
cd frontend
npm install
npm run serve     # dev server with hot reload
npm run build     # production build
npm run lint      # lint and fix files
```
